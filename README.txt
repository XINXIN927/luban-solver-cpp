鲁班锁六柱求解器 v1.0
========================

文件说明：
  luban_win32_gui.exe  — 桌面 GUI（双击运行）
  luban_cli_solver.exe — 命令行求解器
  burr_verify_node.js  — 拆解验证脚本（空心锁需要）

使用方式：
  方法一：双击 luban_win32_gui.exe
  方法二：命令行 luban_cli_solver.exe 733 669 1004 366 99 1023

要求：
  Windows 7 或更高版本
  OpenGL 兼容显卡（集成显卡即可）
  空心锁需安装 Node.js (nodejs.org)

系统要求：
  OpenGL 兼容显卡
  Windows 7 以上
